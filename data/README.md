# Data

Datos del Tasador de Autos con IA (ValorAuto). Ver `docs/priorizacion_casos.md` para el detalle de fuentes.

- `raw/` — datasets originales sin procesar (Craigslist Vehicles Dataset y complementos: Cars.com, US Used Cars Dataset). No versionar archivos pesados aquí; documentar origen y fecha de descarga.
- `processed/` — datasets limpios y listos para entrenamiento (nulos tratados, categorías normalizadas).

No subir datasets completos ni credenciales de descarga a este repositorio.
